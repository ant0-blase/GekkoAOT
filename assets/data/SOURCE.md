# Save-name character mapping

`shift-jis-u16.bin` is a generated, big-endian Unicode lookup table for standard Shift-JIS double-byte sequences. It contains character-mapping data, generated using Python’s `shift_jis` codec; it contains no game data. ASCII and half-width Katakana are decoded directly in code.

Reference: [Python standard encodings](https://docs.python.org/3/library/codecs.html#standard-encodings).
